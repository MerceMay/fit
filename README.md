## 🧠 新手核心原则

1. **动作质量 > 重量** — 宁可轻也要做全程
2. **渐进超负荷** — 每次加 1.25–2.5kg 或 1–2 次
3. **不要力竭** — 每组留 1–2 次余量，技术不崩
4. **睡眠 > 训练** — 7–8 小时睡眠是增肌基础
5. **吃够蛋白质** — 每天 1.6–2.0g/kg 体重
