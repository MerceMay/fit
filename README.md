# 三分化新手训练计划（Push / Pull / Legs + Shoulders）

> 目标：在不影响学习、工作和日常恢复的前提下增肌，并练习卧推、传统硬拉和深蹲三大项。所有正式组默认保留 **1–3 次余力（RIR 1–3）**。

## 周安排

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| 推 A | 拉 A | 腿＋肩 | 休息 | 推 B | 拉 B | 休息 |
| 胸＋三头 | 背＋二头＋传统硬拉 | 腿＋肩前中束 |  | 胸＋三头 | 背＋二头＋后束 |  |

- 推、拉每周各 2 次；腿和肩部直接训练各 1 次。
- 肩前束还会在两次卧推中获得刺激，后束随拉日训练。
- 拉 A 做传统硬拉；拉 B 不再重复硬拉，降低腰背和全身疲劳。
- 腹部每周 2–3 次，每次 2 个动作，不再每天做 4 个动作。

## 热身原则

每次先用跑步机快走、单车或划船机升温 **3–5 分钟**，再做当天的针对性热身。身体已经发热时可以缩短，但不能省略主项的递增热身组。

### 推日热身

| 动作 | 次数 |
|---|---:|
| 肩关节环绕 | 每方向 10 次 |
| 弹力带肩外旋 | 每侧 12–15 次 |
| 弹力带拉开或肩胛俯卧撑 | 12–15 次 |
| 卧推递增热身 | 空杆×12–15 → 50%×8 → 70%×4–5 |

### 拉 A（传统硬拉）热身

| 动作 | 次数 |
|---|---:|
| 猫牛式或胸椎旋转 | 6–8 次 |
| 徒手髋铰链 | 10 次 |
| 空杆罗马尼亚硬拉 | 8–10 次 |
| 硬拉递增热身 | 轻重量×8 → 50%×5 → 70%×3 → 80%×1–2 |

### 拉 B（无硬拉）热身

| 动作 | 次数 |
|---|---:|
| 弹力带拉开 | 15 次 |
| 肩胛引体或轻重量高位下拉 | 10–12 次 |
| 第一个下拉动作递增热身 | 2 组 |

### 腿＋肩日热身

深蹲前：

| 动作 | 次数 |
|---|---:|
| 踝关节前移 | 每侧 10 次 |
| 髋关节环绕 | 每方向 8–10 次 |
| 徒手深蹲 | 10–15 次 |
| 深蹲递增热身 | 空杆×10 → 50%×6 → 70%×3–4 |

肩推前再补：肩关节环绕 10 次、轻重量肩推 1–2 组。不要在训练开始时提前热肩，然后隔二三十分钟才肩推。

## 腹部

每周选 2–3 个训练日，每次做以下两类各一个动作：

- 屈曲/举腿：绳索卷腹、悬垂举腿或反向卷腹，3 组。
- 核心稳定：健腹轮、死虫式、侧桥或 Pallof Press，3 组。

## 进步规则

1. 先固定重量，在目标次数范围内逐渐增加次数。
2. 所有正式组都达到次数上限且动作稳定后，再加最小重量。
3. 深蹲、硬拉、卧推不要每次力竭，通常保留 2 次左右余力。
4. 若腿日持续影响两天以上的学习、走路或下一次训练，先各减 1 组，不要删掉主项。
5. 热身组用于准备动作，不计入正式训练组数。
