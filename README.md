# 新手 PPL 训练计划

> 当前阶段只练收益最高的基础动作：建立力量、动作能力和整体肌肉量。暂不安排大量飞鸟、夹腿、髋外展、前平举及各种细节变式。

## 周安排

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| Push A | Pull A | Legs | 休息 | Push B | Pull B | 休息 |
| 胸＋肩＋三头 | 背＋后束＋二头 | 大腿＋臀＋小腿 | | 胸＋肩＋三头 | 背＋后束＋二头 | |

腿每周一次，因此保留完整但不过量的腿、臀、小腿训练；传统硬拉只在 Pull A 做一次。

## 热身

每次先用跑步机、单车或划船机升温 3–5 分钟，再进行当天针对性热身。热身组不计入正式组。

### Push

- 肩关节环绕：每方向 10 次
- 弹力带肩外旋：每侧 12–15 次
- 肩胛俯卧撑或弹力带拉开：12–15 次
- 卧推递增：空杆×12–15 → 50%×8 → 70%×4–5

### Pull A（硬拉）

- 胸椎旋转：每侧 6–8 次
- 徒手髋铰链：10 次
- 空杆罗马尼亚硬拉：8–10 次
- 硬拉递增：轻重量×8 → 50%×5 → 70%×3 → 80%×1–2

### Pull B（不硬拉）

- 弹力带拉开：15 次
- 肩胛引体或轻重量高位下拉：10–12 次
- 第一个下拉动作做 2 组递增热身

### Legs

- 踝关节前移：每侧 10 次
- 髋关节环绕：每方向 8–10 次
- 徒手深蹲：10–15 次
- 深蹲递增：空杆×10 → 50%×6 → 70%×3–4

## 进步规则

- 大部分正式组保留 1–3 次余力，三大项通常保留约 2 次。
- 同一重量做到所有组均达到次数上限，再增加最小重量。
- 卧推当前可从总重量约 30 kg 开始，先完成规范的 3–4 组，不急着测试极限。
- 连续两周无法增加次数时，先检查动作、睡眠和饮食，不要立即增加更多动作。
- 腹部可每周 2 次、每次 2 个动作；当前不是 PPL 主菜单的重点。

替代动作和以后用于补短板的细节动作见[动作库](动作库.md)。
